## 1. book-to-skill

https://github.com/virgiliojr94/book-to-skill   별 31.8k · 2026-09-18

기술서 한 권, 문서 폴더, 파일 묶음을 스킬 하나로 바꾼다. 만든 뒤 `/책이름 질문` 으로
물으면 에이전트가 해당 장을 읽고 **실제 내용에서** 답한다. 추출은 로컬 도구로 한다.

**여기에 가장 잘 맞는다.** 기억으로 답하면 안 되는 참고서가 많다.

```text
SWMM 5 Reference Manual (수문 · 수리 · 수질)   식 · 기본값 · 절 번호를 묻는다
하수도 설계기준                                조항을 쪽까지 묻는다
실시설계보고서 · 기본설계보고서                  09_원자료 의 1 차 출처
```

`01_공통.md` 의 "기억으로 API 이름이나 수치를 적지 마라" 를 도구로 받치는 셈이다.

**확인할 것.** 한글 PDF 추출이 되는지, 쪽 번호가 살아 남는지. 발주처 보고서는
로컬에서만 돌고 밖으로 나가지 않는지 설치 전에 코드를 본다.

## 2. discernment-nudge (Anthropic 공식)

https://github.com/anthropics/skills/tree/main/skills/discernment-nudge   2026-08-17 추가

분석 · 추정 · 권고처럼 사용자가 그대로 행동할 답을 줬을 때, 끝에 짧은 질문 2-3 개를
붙인다. 어떤 사실을 확인해야 하나, 어느 추론이 건너뛰었나, 무엇을 가정했나.
Anthropic 의 AI Fluency 틀에서 나왔고, 대화마다 한 번만, 코드 · 단순 조회 · 번역에는
걸리지 않는다.

**우리 검증 문화와 같은 방향이다.** `[추정]` · `[판정보류]` 를 답 쪽에서 붙이는 것이라면,
이것은 사용자가 무엇을 확인할지 짚어 준다. 가볍고 공식이라 위험이 적다.

## 3. LLM 위키 방식 (Karpathy)

https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f   [열어봄]

도구가 아니라 방식이다. 올해 4 월 나와 크게 퍼졌다.

```text
raw\      원자료. 에이전트는 읽기만 한다          = 09_원자료\
wiki\     에이전트가 쓰는 요약 · 개념 · 대상 쪽      사람은 읽기만 한다
schema    구조와 규칙을 적은 CLAUDE.md
index.md  분류별 목차. 들일 때마다 갱신
log.md    날짜 순 기록.  ## [2026-04-02] ingest | 문서이름
```

일은 셋이다. **들이기**(새 원자료를 읽고 요약 쪽을 쓰고 관련 쪽 10-15 개를 고친다),
**묻기**(위키에서 찾아 인용과 함께 답하고, 쓸 만한 답은 위키에 다시 쌓는다),
**점검**(서로 어긋난 주장, 낡은 주장, 고아 쪽, 빠진 교차 참조를 찾는다).

**우리 규칙과 잘 맞는다.** 원자료 읽기 전용, 상충 병기, 쪽 번호 인용, 날짜 기록이
이미 있다. `22_문서분석.md` 가 문서 하나를 판정하는 법이라면, 이것은 판정을 쌓아
두고 다음 세션이 다시 읽지 않게 하는 법이다. 들이려면 지침 파일 하나(예: `23_위키.md`)
와 들이기 · 묻기 · 점검 스킬로 만든다.

## 5. rtk

https://github.com/rtk-ai/rtk   별 81.3k · 2026-09-21   Apache-2.0

에이전트가 부르는 셸 명령의 출력을 줄여서 넘긴다. 같은 일에 토큰을 60-90% 덜 쓴다고

출력을 본다" 는 규칙과 부딪힐 수 있으니 켜기 전에 점검 · 모의 로그가 온전히 보이는지
시험한다. 훅을 심는지도 설치 전에 본다.

## 조사하다 찾은 우리 쪽 문제

**claude.ai 스킬이 Claude Code 로 내려온다.** 공식 문서(code.claude.com/docs/en/skills):
claude.ai 계정의 스킬은 세션 시작 때 `~/.claude/skills/synced/` 로 내려받고 10 분마다
다시 본다. 이름이 같으면 로컬이 이기고 내려온 것은 `anthropic-skills:이름` 으로 남는다.

지금 내려와 있는 것이 18 개인데, 그중 `docx` · `pdf` · `pptx` · `xlsx` 등은 로컬
`~/.claude/skills/` 에도 있어 **매 세션 목록에 두 번씩 실린다.**
그리고 `std-*.zip` 을 claude.ai 에 올리면 우리 스킬도 두 벌이 된다.

```text
가  syncClaudeAiSkills: false     이 PC 에서 내려받기를 끈다. 웹에는 올려도 된다
나  웹에 std-* 를 올리지 않는다     웹 채팅은 개인 선호 글만 쓴다
다  로컬의 docx · pdf 등을 치운다   내려온 쪽만 쓴다
```

**권하는 것은 가.** 이 PC 는 `Prompt` 원본을 정션으로 직접 보므로 내려온 사본이 필요
없고, 웹에 올린 옛 zip 이 로컬보다 뒤처져도 섞이지 않는다.
