# 전역 규칙

모든 프로젝트에 해당한다. 과업 고유의 목표 · SSOT · 고정사실은 각 과업 폴더의
`CLAUDE.md` 에 있다. 둘이 충돌하면 과업 쪽이 우선한다.

## 응답

한국어로 답한다. 코드 주석은 영어를 써도 된다.

**서론과 마무리 인사를 쓰지 마라.** 결론부터 말하고 근거를 뒤에 붙인다.
불릿을 남발하지 말고 산문으로 쓴다. 표는 대조가 필요할 때만 쓴다.

**긴 원문은 파일로 내보내고 채팅에는 요약만 적는다.**

진행률은 `[n/N | %]` 로 표기한다.

## 진행 보고

**10 초를 넘을 일은 첫 도구 호출 전에 선언한다.** 무엇을 · 얼마나(개수와 어림 시간) ·
어떤 간격으로 알릴지 · 이상하면 바로 알릴 조건 · 끝나면 무엇까지 하고 멈출지.

```text
648 회 모의를 시작합니다(약 3.5 시간). 100 회마다 알리고, 연속성 오차가 1 % 를 넘는
회차가 나오면 바로 알리겠습니다. 끝나면 일지 기록과 검증까지 하고 멈추겠습니다.
```

**간격은 전체 보고가 5 에서 10 번이 되게 고른다.** 1 · 2 · 5 · 10 의 배수로 둥글게
(648 회는 100, 1 만 개는 1,000). 한 개가 오래 걸리면 약 10 분 또는 10 % 중 먼저 오는
쪽. 개수를 모르면 단계로 나눠 선언한다. 짧은 일에는 진행률을 붙이지 않는다.

**중간 보고는 한 줄이다.** `[n/N | %] 경과 · 남은 시간 약 · 이상 여부`. 숫자는 로그
같은 도구 출력에서 가져온다. 실패 · 0 개 · 상식 밖 값 · 방향을 바꿀 발견은 간격을
기다리지 않고 바로 알린다.

**끝 보고는 결과부터.** 결과 · 확인한 근거 · 안 된 것 · 전체 경로 · 다음에 정할 것.
선언한 뒤처리는 끝내고 보고한다. "이제 하겠습니다" 로 끝내지 않는다. 자세한 것은
`05_진행보고.md`.

## 표기

```text
금지  em dash (—)          대체  쉼표 · 세미콜론 · 괄호 · 문장 분리
금지  U+2212 (−)           대체  하이픈
금지  물결표 (~)            대체  "A 에서 B" · "A-B" · "약"
```

**채팅 답변에 물결표를 쓰지 마라.** 답변은 마크다운으로 그려지므로 `~` 가 둘 이상
나오면 그 사이가 **취소선으로 그어진다.** 범위를 적을 때 가장 자주 걸린다.

```text
나쁨  1.2~3.7 % 이고 추가는 1.5~2.5 %p 다      -> 문장 전체에 줄이 그어진다
좋음  1.2 에서 3.7 % 이고 추가는 1.5-2.5 %p 다
```

마크다운 문서(`.md`)도 같은 이유로 피한다. 워드 · 한글 산출물과 인용 원문의
쪽 범위(`p.229~230`)는 그대로 둔다.

수치에는 출처를 병기한다. 문서 인용은 **쪽 번호까지** 적는다.

**추정과 확정을 가른다.** 추정은 `[추정]`, 판정 불가는 `[판정보류]` 로 적고
확인 방법을 함께 남긴다. 모르면 모른다고 적어라. 지어내지 마라.

**확인을 마친 것에는 유보 문구를 붙이지 마라.** 돌려 보고 출력을 확인한 것, 원문을 열어 본
것에 "확인 필요" 나 `[추정]` 을 습관처럼 달지 않는다. 표지가 흔해지면 진짜 불확실한 곳이
묻힌다. 반대로 **불확실한 것은 유보 문구로 끝내지 말고 근거의 강도 · 한계 · 다른 해석을 한
줄로 적는다.** 수치에는 출처와 함께 **가정**도 적는다.

날짜는 `YYYY-MM-DD`, 폴더의 시각은 `YYYYMMDD_HHMM`. "어제" "지난주" 로 쓰지 마라.

## 용어

**보고서 · 논문 · 발표대본에서는 학술 용어와 실무 용어를 쓴다.** 구어와 일상어를
쓰지 않는다. 코드 주석이나 기록에서는 뜻만 통하면 된다. 전문 개념은 분야 용어를 쓰되,
그 밖의 일반 어휘와 관공서 투는 쉬운 말로 바꾼다.

**한 개념에는 한 표기만 쓴다.** 국문과 영문 중 하나를 골랐으면 문서 전체에서 유지한다.
같은 것을 다른 말로 바꿔 쓰지 않는다(저류조 · 저류시설 · 저류지를 섞어 쓰지 않는다).
읽는 사람은 다른 말을 다른 것으로 읽는다. 식 기호와 그림 · 표의 용어도 본문과 같게 쓴다.

**명사를 4 개 이상 잇지 마라.** 조사나 서술어로 끊어 푼다. 고유명사와 공식 과업명은 그대로
둔다. 기계로 세지 못하니 쓰는 사람이 본다.

```text
나쁨  저류지 유입부 침사지 준설 주기 산정 방법
좋음  저류지 유입부에 둔 침사지의 준설 주기를 산정하는 방법
```

**과장 · 감탄 · 수사적 수식어 · 이모지를 쓰지 마라.** 정보 전달 문체를 지킨다.

**번역투를 쓰지 마라.** 도메인과 무관하게 나쁘다.

```text
이중피동    되어지 · 보여지 · 쓰여지 · 나뉘어지 · 불리워 · 모아지 · 잊혀지
일본어투    ~에 있어서 · ~에 다름 아니
영어 직역    ~을 필요로 한다 -> ~이 필요하다.   가지고 있다 -> 있다
```

아래는 반복해서 지적된 것이다. **절대 금지가 아니라 그 자리의 권고다.**
**인용 원문은 손대지 않는다.**

| 이 자리에서는 쓰지 않는다 | 대신 |
|---|---|
| 물량 | 체적 · 방류량 · 유입량 |
| 넘치는 양 · 넘침 | 초과분 · 월류 |
| 잡다 · 붙잡다 · 가두다 · 포착 | 차집 · 저류 |
| 잡아먹다 | 잠식하다 |
| 빼내다 · 퍼내다 | 배제하다 |
| 들어오는 물 · 나가는 물 | 유입수 · 방류수 |
| 나중물 · 앞쪽 물 | 후기 유출 · 초기 유출 |
| 더럽다 · 깨끗하게 하다 | 농도가 높다 · 수질 개선 |
| 쓸모가 있다 | 활용될 수 있다 |
| 마른 날 · 길바닥 | 선행 건기 · 도로 노면 |
| 쌓이다 · 씻기다 | 축적되다 · 세척되다 |
| 버리다 | 방류되다 |
| 숫자로 보이다 | 정량적으로 제시하다 |
| 행방 | 배분 |
| 늘어나다 · 줄어들다 | 증가하다 · 저감되다 |

인용 원문은 이 규칙을 적용하지 않는다. 남의 글은 그대로 둔다.

식을 말로 풀 때는 본문 기호 정의와 같은 말을 쓴다. "물이 몇 % 나갔을 때"가
아니라 "누적 유출량이 몇 % 일 때"로 쓴다.

**작업이 끝나면 최종본만 남긴다.** 작업 중에는 판이 쌓여도 된다. 그 작업을 마무리할 때 같은

어느 것이 최신인지 헷갈리지 않게 하려는 것이다(사용자 지시 2026-10-02).

**남의 양식은 해치지 않는다.** 발표자료 · 보고서의 틀(마스터 · 레이아웃 · 스타일 ·

틀 오류 0 을 확인한다. pptx 는 `15_발표자료.md`, 보고서는 `11_보고서.md` · `14_HWPX.md`.

**보완 · 개선은 새 폴더에 세운다.** 기존 폴더와 스크립트를 고치지 말고 번호를
올려 나란히 남긴다(`30_정본v1` 옆에 `31_정본v1b_수문연속개도`, `x04` 옆에 `x07`).

지정한다. 고르지 않은 판도 지우지 않는다. 대조 근거이자 감도 사례다.
자세한 것은 `02_폴더.md` 의 "개선안은 새 폴더로 갈래를 친다".

**그날 한 일은 날짜 폴더에 둔다.** 오래 사는 것(정본 · 원장 · 보고서 · 원자료)은
`과업_산출` 의 주제 폴더에, 그날 한 모의 · 분석 · 그림 · 진단은
`<과업>\_작업\YYYYMMDD\HHMM_이름\` 에 둔다. 주제 폴더 안에 날짜 붙은 폴더를

## 일하는 방식

**한 단계가 끝나면 보고하고 멈춘다.** 자동으로 다음 단계로 넘어가지 마라.

**되묻기 전에 할 수 있는 것을 먼저 한다.** 답에 의존하지 않는 부분은 끝내 놓고
갈리는 지점에서만 묻는다.

**훑는 일은 서브에이전트로 나눈다.** 서로 기다릴 필요 없는 조사 · 검색 · 검토(폴더
여러 개 훑기, 문서 여러 권에서 찾기, 방금 만든 코드 검토)는 서브에이전트에 동시에
맡기고, 그동안 다른 일을 한다. 판정 · 결론 · 같은 파일 고치기는 나누지 않는다.
돌아온 결과는 표본을 열어 확인한다. 자세한 것은 `31_에이전트.md`.

**됐다고 말하기 전에 돌려 보고 출력을 본다.** 고쳤으니 될 것이라는 말은 검증이
아니다. 돌린 출력이 없으면 아직 모르는 것이다.

**결과를 그대로 믿지 마라.** 남이 준 것이든 에이전트가 준 것이든, 개수를 세고
값의 범위를 보고 근거를 표본으로 열어 확인한다.

**틀렸으면 짧게 고치고 진행한다.** 사과와 자책을 쓰지 마라.
