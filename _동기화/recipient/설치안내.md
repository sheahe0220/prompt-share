# Claude 작업 지침 설치 안내

이 폴더는 Claude(클로드)에게 일을 시킬 때 매번 설명하지 않아도 되도록 모아 둔 작업 지침입니다.
한 번 설치하면 앞으로 여는 **모든 새 대화**에 자동으로 적용됩니다.

## 준비물

Claude 데스크톱 앱(유료 요금제, "Code" 탭이 보여야 함). Python 같은 다른 프로그램은 없어도
됩니다. 필요하면 설치 과정에서 클로드가 물어보고 도와줍니다.

## 설치 (5 분)

1. 이 폴더를 원하는 곳에 둡니다. 예: `C:\Claude\Prompt`. 설치한 뒤에도 폴더를 지우지 마세요.
2. Claude 앱에서 왼쪽 위 **Code** 를 누르고, 아래 입력창 위의 **로컬** 을 고른 뒤 **폴더** 에서
   이 폴더를 선택합니다.
3. 입력창에 **"이 폴더 지침을 이 PC 에 설치해줘"** 라고 씁니다.
4. 클로드가 PC 를 점검하고, 무엇을 할지 설명하고, 몇 가지를 묻습니다. 명령 실행 허락을
   물으면 **허용** 을 누릅니다.
5. 끝나면 **새 대화** 를 엽니다. 이때부터 지침이 적용됩니다.

클로드에게 맡기지 않고 지침만 넣으려면 폴더의 `설치하기.bat` 을 더블클릭해도 됩니다.

## 알아 둘 것

- 이 지침은 원래 수문 · 수자원 연구자가 자기 일에 맞춰 쓴 것입니다. 설치할 때 클로드가 하는 일
  (예: 토목 설계)과 쓰는 프로그램을 묻고 **"이 PC 메모"** 에 적어 두며, 그다음부터는 그 메모에
  맞춰 지침을 골라 씁니다.
- 기존 설정은 지우지 않고 백업합니다.
- 이미 열려 있던 대화에는 적용되지 않습니다. 새 대화를 여세요.
- `시작하기.md` 대로 설치했다면 원작자가 지침을 고칠 때마다 클로드를 열면 자동으로 새 판이
  들어옵니다. "이 PC 메모" 는 그대로 남습니다. 여러분의 파일이나 대화는 어디에도 올라가지 않습니다.
- 받은 폴더(`C:\claude-prompt`) 안의 파일은 고치지 마세요. 새 판을 받을 때 막힙니다.
- 여러분의 과업 자료를 이 폴더에 넣지 마세요.

## 되돌리기

Code 탭에서 이 폴더를 열고 "설치한 지침을 되돌려줘" 라고 하면 됩니다.
