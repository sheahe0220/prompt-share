# 도구 목록 (원작자 PC 에 깔린 것 전부)

클로드가 이 PC 사용자의 일에 빗대어 하나씩 묻는 데 쓴다. 쓰는 법은 시작하기.md 3 부.

### 기본 (10 개)  2-4 에서 깔았다

    [확장] 클로드 코드 (공식)   anthropic.claude-code
        무엇  Anthropic 이 직접 만든 공식 확장입니다. VS Code 안에서 클로드에게 일을 시키고, 클로드가 고치려는 내용을 편집 창에서 바로 보여 줍니다.
        예    하천 설계보고서 폴더를 열어 두고 "3 장 수리계산 표의 단위를 맞춰 줘" 라고 말하면, 고칠 곳을 화면에 띄워 보여 주고 승인을 받은 뒤 고칩니다.
        조건  Claude 유료 요금제(Pro, Max, Team, Enterprise) 또는 사용량 과금 계정이 필요합니다.
        설치  code --install-extension anthropic.claude-code

    [확장] 한글 문서 보기 (rhwp)   edwardkim.rhwp-vscode
        무엇  한글(HWP, HWPX) 문서를 한컴오피스 없이 VS Code 안에서 열어 봅니다. 쪽 이동, 확대, 개요(목차) 이동이 되고 문서가 밖으로 전송되지 않습니다. 보기 전용입니다.
        예    하천 설계보고서 hwpx 를 클로드가 고친 뒤, 한글 프로그램을 따로 켜지 않고 VS Code 안에서 바로 열어 표와 그림이 제자리에 있는지 확인할 때 씁니다.
        설치  code --install-extension edwardkim.rhwp-vscode

    [확장] PDF 보기   mathematic.vscode-pdf
        무엇  PDF 파일을 VS Code 안에서 엽니다. 파이어폭스와 같은 PDF 엔진(PDF.js)을 써서 가볍습니다.
        예    상수도 시설기준 PDF 와 설계계산서를 한 화면에 나란히 띄워 놓고 조항을 대조할 때 씁니다.
        설치  code --install-extension mathematic.vscode-pdf

    [확장] CSV 색칠 보기   mechatroner.rainbow-csv
        무엇  쉼표로 나눈 표 파일(CSV, TSV)의 열마다 색을 달리 칠해 읽기 쉽게 합니다. 간단한 조건 검색도 됩니다.
        예    강우 관측 자료나 관로 제원표 CSV 를 열었을 때 어느 값이 몇 번째 열(관경, 경사, 연장)인지 색으로 바로 구분됩니다.
        설치  code --install-extension mechatroner.rainbow-csv

    [확장] 한국어 화면   ms-ceintl.vscode-language-pack-ko
        무엇  VS Code 의 메뉴와 안내 문구를 한국어로 바꿔 줍니다.
        예    영문판 CAD 메뉴를 한글판으로 바꿔 쓰는 것과 같습니다. 처음 VS Code 를 켰을 때 메뉴를 알아보기 쉽게 해 줍니다.
        설치  code --install-extension ms-ceintl.vscode-language-pack-ko

    [확장] 워드 문서 보기   shahilkumar.docxreader
        무엇  워드(docx)와 오픈오피스(odt) 문서를 VS Code 안에서 열어 봅니다. 목차 이동, 찾기, 확대가 됩니다. 보기 전용입니다.
        예    발주처가 보낸 과업 검토의견서 docx 를 워드를 켜지 않고 VS Code 안에서 열어 클로드와 함께 읽을 때 씁니다.
        설치  code --install-extension shahilkumar.docxreader

    [확장] 파일 아이콘   vscode-icons-team.vscode-icons
        무엇  파일 목록에서 확장자마다 알아보기 쉬운 그림(아이콘)을 붙여 줍니다.
        예    설계 폴더에 hwpx, pdf, xlsx, dwg 목록이 섞여 있을 때 종류를 아이콘으로 한눈에 구분합니다.
        설치  code --install-extension vscode-icons-team.vscode-icons

    [플러그인] 클로드 설정 도우미   claude-code-setup@claude-plugins-official
        무엇  지금 폴더를 훑어보고 Claude Code 를 더 편하게 쓸 자동화(훅, 스킬, 외부 연결, 보조 에이전트)를 추천해 준다.
        예    새 과업 폴더를 만들고 나서 '이 폴더에서는 무엇을 자동으로 해 두면 좋을까' 를 물어볼 때, 현장 착수 전 장비 점검표를 받아 보는 것과 비슷하다.
        조건  추천만 하고 스스로 설치하지는 않는다. 추천 내용은 코드 폴더 기준이 많아 일부는 건너뛴다.
        설치  claude plugin install claude-code-setup@claude-plugins-official

    [플러그인] 작업 규칙 파일 관리   claude-md-management@claude-plugins-official
        무엇  클로드가 매번 읽는 규칙 파일(CLAUDE.md)의 품질을 점검하고, 대화에서 배운 것을 규칙 파일에 보태 준다.
        예    과업마다 '보고서 표기는 이렇게, 수치는 출처와 함께' 같은 약속을 적어 둔 업무지침서를 다듬고 최신으로 유지할 때.
        설치  claude plugin install claude-md-management@claude-plugins-official

    [장터] Anthropic 공식 장터   claude-plugins-official
        무엇  Claude 를 만든 Anthropic 이 운영하는 공식 플러그인 목록. 이 목록의 플러그인 가운데 일부는 GitHub, Figma, Stripe 같은 다른 회사가 만들었다.
        예    공식 조달 목록처럼, 여기서 고른 것은 일단 출처가 분명하다.
        조건  Claude Code 에 기본으로 들어 있을 수 있다 [추정]. claude plugin marketplace list 로 확인하고 없을 때만 추가한다.
        설치  claude plugin marketplace add anthropics/claude-plugins-official

        예    hwpx 파일 속은 XML 로 되어 있어서, 클로드가 한글 문서 속을 직접 뜯어 볼 때 사람이 내용을 확인하는 데 쓸 수 있습니다. 대부분은 필요 없습니다.

        예    클로드가 보고서 파일을 여러 번 고친 이력을 깃으로 남겨 두었다면, 어느 시점 판으로 돌아갈지 그림으로 보고 고를 때 씁니다. 도면 개정 이력표를 그림으로 보는 것과 비슷합니다.
        조건  Git 프로그램이 설치되어 있어야 합니다.
        설치  code --install-extension mhutchie.git-graph

    [확장] 파이썬 오류 추적   ms-python.debugpy
        무엇  파이썬 프로그램을 한 줄씩 멈춰 가며 돌려 보고, 그때 값이 무엇인지 확인하게 해 줍니다.
        예    파이썬 확장을 깔면 같이 깔립니다. 계산 스크립트가 틀린 값을 낼 때 어디서 틀렸는지 직접 따라가 보는 사람용입니다.
