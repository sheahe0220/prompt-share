# 1. 한눈에 보기: 일하는 순서

VS Code 는 파일을 보고 고치는 창이고, 클로드 코드는 그 창 안에서 일을 대신 해 주는 도우미입니다. 날마다 하는 순서는 다섯 단계입니다.

① **파일 > 폴더 열기** 로 오늘 일할 과업 폴더를 엽니다.
② 왼쪽 세로 막대의 **클로드 아이콘(불꽃 모양)** 을 눌러 세션 목록을 엽니다.
③ **새 대화(세션)** 를 시작하거나, 어제 하던 세션을 골라 이어서 합니다.
④ 파일 경로를 복사해 붙이고, 무엇을 해 달라고 한국어로 씁니다. Enter 로 보냅니다.
⑤ 클로드가 고친 내용을 확인하고, 끝나면 "오늘 한 일 세션기록에 저장해줘" 라고 합니다.

# 2. VS Code 기초

## 2-1. 폴더 열기

① 맨 위 메뉴 **파일** 을 누릅니다.
② **폴더 열기...** 를 누릅니다(단축키 **Ctrl+K** 다음 **Ctrl+O**).
③ 과업 폴더(예: D:\과업\2026_○○천)를 고르고 **폴더 선택** 을 누릅니다.

[그림 f02_폴더열기.png | 파일 메뉴의 "폴더 열기". 처음 여는 폴더는 "이 폴더에 있는 파일의 작성자를 신뢰합니까?" 를 묻습니다. 내 과업 폴더면 "예, 작성자를 신뢰합니다" 를 누릅니다.]

**폴더를 여는 까닭:** 클로드는 연 폴더 안만 보고, 대화(세션)도 폴더마다 따로 쌓입니다. 과업마다 폴더를 따로 열면 과업끼리 섞이지 않습니다.

@주의 문서 폴더나 바탕화면 전체를 열지 마세요. 클로드가 그 안의 모든 파일을 볼 수 있습니다. 과업 폴더 하나만 여세요.

**명령 팔레트(Ctrl+Shift+P)** 는 "메뉴를 못 찾겠을 때" 쓰는 검색창입니다. 하고 싶은 일을 영어나 한국어로 치면 명령이 나옵니다. 예를 들어 "Claude Code" 를 치면 클로드 관련 명령이 모두 나옵니다.

## 2-3. 화면을 한국어로

한국어 화면 확장은 설치 때 깔립니다. 영어로 나오면 ① **Ctrl+Shift+P** ② "display" 를 쳐서 **Configure Display Language**(한국어 화면에서는 "표시 언어 구성") ③ 한국어 ④ 다시 시작 순서로 바꿉니다.

## 2-4. 여러 과업 폴더를 한 창에 (작업 영역)

**파일 > 작업 영역에 폴더 추가...** 로 폴더를 더 넣고, **파일 > 작업 영역을 다른 이름으로 저장...** 으로 저장하면 .code-workspace 파일이 생깁니다. 그 파일을 두 번 누르면 같은 묶음이 다시 열립니다. 처음에는 과업 폴더 하나씩 여는 편이 헷갈리지 않습니다.
@쪽나눔

# 3. 클로드 창 열고 세션 시작하기

## 3-1. 클로드 창 여는 네 가지 방법

@표
어디서 | 어떻게
왼쪽 작업 막대 | 클로드 아이콘(불꽃 모양)을 누르면 세션 목록이 열립니다. 항상 보입니다.
편집 창 오른쪽 위 | 파일을 하나 연 상태에서 불꽃 아이콘을 누릅니다.
명령 팔레트 | Ctrl+Shift+P 에서 "Claude Code" 를 치고 Open in New Tab 등을 고릅니다.
오른쪽 아래 상태 표시줄 | ✻ Claude Code 를 누릅니다(설정에 따라 보입니다).
@끝

처음 열면 **Sign in** 이 나옵니다. 누르고 브라우저에서 Claude 계정으로 승인하면 됩니다.

## 3-2. 세션이란

세션은 **대화 한 줄기** 입니다. 한 세션 안에서는 앞에 한 말을 기억합니다. 세션은 연 폴더마다 따로 쌓입니다. 같은 폴더를 다시 열면 그 폴더의 지난 세션들이 목록에 다시 나옵니다.

[그림 f03_세션목록.png | 작업 막대의 클로드 아이콘을 누르면 이 폴더의 세션 목록이 열립니다. ① 새 대화 ② 지난 세션(누르면 이어서 합니다) ③ 그룹 ④ 상태 거르기]

① **새 대화** 를 누르면 빈 대화가 시작됩니다. 서로 관계없는 일은 새 대화로 시작하는 편이 좋습니다(앞 대화가 섞이지 않습니다).
② 지난 세션을 누르면 그 대화가 열리고 이어서 시킬 수 있습니다. 창 위쪽의 **Session history** 에서 낱말로 찾을 수도 있습니다.
③ 세션을 오른쪽 클릭하면 그룹으로 묶을 수 있습니다(예: "중간보고", "심의 대응"). 그룹은 폴더마다 저장됩니다.
④ 깔때기 모양으로 상태별(입력 기다림, 일하는 중, 끝남)로 거를 수 있습니다.

@작게 14 일 동안 쓰지 않은 세션은 자동으로 보관(Archived sessions)으로 옮겨집니다. 지워진 것이 아니니 보관 목록에서 되살리면 됩니다.

## 3-3. 세션 여러 개 동시에

명령 팔레트의 **Open in New Tab**(Ctrl+Shift+Esc) 이나 **Open in New Window** 로 대화를 더 엽니다. 대화마다 기억이 따로입니다. 예를 들어 한 탭에서는 보고서 3 장을 고치고, 다른 탭에서는 수리계산서 표를 정리시킬 수 있습니다.

탭의 불꽃 아이콘에 점이 붙습니다. **파란 점** 은 허락을 기다리는 중, **주황 점** 은 안 보는 사이에 일이 끝났다는 뜻입니다.

@팁 원작자는 세션을 여러 개 동시에 돌리는 일이 많습니다(기록상 동시에 겹친 세션이 백 쌍이 넘습니다). 긴 일을 시켜 놓고 다른 탭에서 다른 일을 시키면 기다리는 시간이 줄어듭니다. 단, **같은 파일을 두 세션이 동시에 고치게 하지는 마세요.**
@쪽나눔

## 4-2. 파일 경로 복사해서 주기 (가장 많이 쓰는 방법)

VS Code 에서는 파일을 붙여 넣기보다 **경로를 복사해서 주는 것** 이 일반적입니다. 클로드가 그 경로의 파일을 직접 열어 읽습니다. Claude 데스크톱 앱에서 파일을 끌어다 올리던 것과 다릅니다.

**VS Code 탐색기에서**
① 파일을 오른쪽 클릭합니다.
② **경로 복사** 를 누릅니다(단축키 **Shift+Alt+C**). 과업 폴더 기준으로 짧게 주려면 **상대 경로 복사** 를 누릅니다.
③ 입력창에 Ctrl+V 로 붙이고 할 일을 씁니다.

[그림 f05_경로복사.png | 탐색기에서 파일을 오른쪽 클릭하면 나오는 메뉴. "경로 복사" 는 C:\ 부터 전체 경로, "상대 경로 복사" 는 연 폴더 기준 경로입니다.]

지금 편집 창에 연 파일의 경로는 **Ctrl+K** 다음 **P** 로 복사됩니다.

**Windows 파일 탐색기에서**
파일을 고르고 **Ctrl+Shift+C** 를 누르면 경로가 복사됩니다. 오른쪽 클릭 메뉴의 **경로로 복사** 로도 됩니다(안 보이면 Shift 를 누른 채 오른쪽 클릭). 따옴표가 붙어 복사되는데, 그대로 붙여도 됩니다.

## 4-3. 원작자가 명령하는 방식

원작자는 경로나 붙여 넣은 글 뒤에 **<<** 를 붙이고 무엇을 할지 씁니다. 짧고 편한 말로 써도 클로드는 알아듣습니다.

@상자 예 | "D:\과업\2026_○○천\보고서\3장_수리검토.hwpx" << 표 3-2 숫자가 수리계산서랑 맞는지 확인해줘
(메일 본문 붙여 넣기) << 발주처 요구사항만 뽑아서 할 일 목록으로 정리해줘
(캡처 붙이기) << 이 오류 뭐야? 고쳐줘
"D:\과업\2026_○○천" << 폴더 구조 분석부터 해줘. 고치지는 말고 보고만

Edit automatically | 파일 고치기까지 | 초안 쓰기처럼 고칠 것이 많을 때

Auto | 대부분. 따로 검사하는 장치가 위험한 것을 거릅니다 | 익숙해진 뒤 (원작자는 거의 이것)
@끝

@주의 Auto 도 완벽하게 안전하지는 않습니다. 발주처 원본 자료가 있는 폴더에서는 Manual 이나 Plan 으로 시작하세요.

## 5-2. 모델 바꾸기

입력창 아래의 **모델 이름** 을 누르거나 / 메뉴의 **Switch model...** 을 고릅니다. 입력창에 **/model** 을 쳐도 됩니다.

@표
이름 | 특징
opus | 기본값. 대부분의 일에 알맞습니다
fable | 가장 어렵고 오래 걸리는 일용. 요금제에 따라 추가 사용량으로 청구될 수 있어 쓰기 전에 묻습니다
sonnet | 조금 가볍고 빠릅니다
haiku | 간단한 일용
opus[1m] 등 [1m] | 아주 긴 자료를 한 번에 다룰 때(100 만 토큰)
@끝

같은 선택창의 **Effort** 줄에서 "얼마나 깊이 생각할지" 를 고릅니다. 높을수록 꼼꼼하지만 느립니다.

@팁 원작자는 평소 opus 로 일하고, 어려운 분석은 fable, 가벼운 정리는 sonnet 으로 바꿔 씁니다. 긴 보고서 여러 권을 한꺼번에 볼 때는 [1m] 판을 고릅니다.

## 5-3. 사용량 보기

**/usage** 를 치면 이번 세션 사용량과 요금제 한도가 나옵니다. 입력창 근처의 표시는 대화가 얼마나 찼는지 보여 줍니다. 가득 차면 자동으로 요약되고, **/compact** 로 직접 요약시킬 수도 있습니다.
@쪽나눔

# 6. 세션 관리와 이어서 하기

클로드는 세션이 바뀌면 앞 세션의 대화를 기억하지 못합니다. 그래서 원작자의 첫째 원칙은 **"파일에 남긴 것만 남는다"** 입니다.

## 6-1. 과정과 결과를 파일로 남기기

일이 한 덩어리 끝날 때, 방향이 바뀌었을 때, 대화가 길어졌을 때, 하루를 마칠 때 이렇게 시킵니다.

@상자 이렇게 말하기 | 지금까지 한 것 세션기록에 저장해줘
오늘 한 일 정리해서 일지 써줘. 방향 바뀐 곳이랑 틀렸던 것도 적어
다음 세션이 이어서 할 수 있게 작업재개 안내 갱신해줘

@표
파일 | 담는 것
00_세션기록\YYYY-MM-DD_세션기록.md | ① 오간 이야기(방향이 바뀐 지점) ② 찾은 것(근거 · 쪽 번호) ③ 만든 것(파일 목록) ④ 다음에 할 것
00_총괄\01_작업재개_안내.md | 0 절에 "지금 상태와 먼저 읽을 파일". 새 세션이 가장 먼저 읽습니다
@끝

@주의 나중에 몰아서 쓰지 마세요. 무엇을 왜 했는지는 그때만 압니다. 특히 "이렇게 하려다가 지적을 받고 바꿨다" 가 가장 중요한 기록입니다.

## 6-2. 다른 세션에서 이어서 하기

[그림 f09_이어하기.png | 세션 A 가 기록 파일에 남기고, 새 세션 B 가 그 파일을 읽고 이어서 합니다.]

## 6-3. 열린 다른 세션에 전달하기

세션을 여러 개 열어 두었을 때, 한 세션에서 정한 규칙이나 결과를 다른 세션에 알리게 할 수 있습니다. 원작자는 "열려 있는 다른 세션들에도 이 규칙 전달해줘" 처럼 자주 씁니다. 받은 세션은 다음 차례에 그 내용을 읽습니다.

@주의 다른 세션에 전달된 부탁은 그 세션의 권한 안에서만 처리됩니다. 한 세션에서 거절된 일을 다른 세션에 시켜 우회하지는 않습니다.

## 6-4. 세션은 어디에 저장되나, 옮길 때 주의

# 9. 밖에서 이어서 하기 (Remote Control)

회사 PC 에서 돌고 있는 세션을 휴대폰 Claude 앱이나 웹(claude.ai/code)에서 이어서 볼 수 있습니다. 실제 일은 계속 회사 PC 에서 하므로 파일과 설정이 그대로 쓰입니다.

① 이어서 볼 세션의 입력창에 **/remote-control** (또는 **/rc**) 를 치고 보냅니다.
② 입력창 아래에 **Remote Control** 표시가 생기고, 대화에 세션 주소가 나옵니다.
③ 휴대폰 Claude 앱의 **Code** 메뉴에서 그 세션을 찾아 엽니다(켜져 있으면 컴퓨터 아이콘에 초록 점).
④ 끄려면 **/remote-control** 을 다시 칩니다.

@주의 VS Code 를 닫거나 PC 가 꺼지면 연결이 끊깁니다. 휴대폰에서 고를 수 있는 권한 모드는 Manual · Accept edits · Plan 입니다. 발주처 자료를 다루는 세션이면 회사 규정을 먼저 확인하세요.

@작게 모든 세션을 자동으로 연결하려면 / 메뉴 Settings 의 **Enable Remote Control for all sessions** 를 켭니다.
@쪽나눔
